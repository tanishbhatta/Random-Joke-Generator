# Random Joke Generator

A small web project I built while learning JavaScript.

The idea is simple: click a button and get a random joke. The jokes are fetched from an external API and displayed directly on the page.

## What I used

- HTML
- CSS
- JavaScript
- Fetch API

## How it works

```text
Click the button
      ↓
JavaScript sends a request to the API
      ↓
The API returns a joke
      ↓
The joke is displayed on the page
